# Customer Churn Prediction

A machine learning project that predicts whether a customer is likely to churn based on customer and service information.

## Features

* Age
* Gender
* Tenure
* Monthly Charges
* Contract Type
* Internet Service
* Total Charges
* Tech Support

## Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost

## Evaluation

Models were evaluated using:

* Accuracy
* Confusion Matrix
* Classification Report

## Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* XGBoost
* Streamlit
* Joblib

## Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```
